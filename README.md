# Hannus autohuolto

Demo website for Hannus autohuolto, a full-service car maintenance garage at Hannuksenpelto 2A, 02270 Espoo (Suomenoja area).

This is a single-file static site: all CSS and JavaScript live inside `index.html`, with no build step and no dependencies. The only external resources are Google Fonts and Unsplash photos.

## How to open

Double-click `index.html` to open it in a browser, or serve the folder statically, for example:

```
npx serve .
```
